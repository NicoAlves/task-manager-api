# Task Manager API

API REST de gestion de tâches développée avec Symfony.

## Fonctionnalités
- Authentification JWT
- CRUD des tâches
- Gestion de statuts personnalisés par utilisateur
- Statuts par défaut
- API REST sécurisée

## Stack technique
- PHP 8.2 / Symfony
- MySQL 8
- Docker & Docker Compose
- Doctrine ORM
